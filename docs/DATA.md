# Данные и обновление

## Расписание

Пользовательский источник: [schedule.uust.ru](https://schedule.uust.ru/). Группа для проверки: [ТОП-106Б, id 14381](https://schedule.uust.ru/schedule?type=0&id=14381). Справочник подтвердил соответствие группы и идентификатора 27 сентября 2026 года.

Обнаруженный общедоступный интерфейс:

```text
GET https://dev.uust-time.ru/api/v/852972/groups?site=schedule
GET https://dev.uust-time.ru/api/v/852972/schedule/0/{groupId}/semester/241?site=schedule
```

Это интерфейс, используемый текущим сайтом, без гарантии стабильного публичного API. Код сайта в приложение не включён. Адаптер интерфейса написан отдельно.

`241` соответствует учебному году 2026/2027. Первая учебная неделя начинается в понедельник 31 августа 2026; календарная конфигурация находится в `app/data/config.json`. При смене года нужно перепроверить идентификатор, даты и формат ответа. Адрес и версия API заданы в `android/src/ru/uust/campus/MainActivity.java` и `tools/preview.py`; значение `apiBase` в JSON служит справочной записью.

Нормализация находится в `app/core.js`, загрузка и сохранение — в `app/repository.js`. Неожиданный формат или данные другой группы не заменяют исправный кеш. Встроенный снимок ТОП-106Б подписан датой загрузки и не выдаётся за актуальное онлайн-обновление.

Сопоставление со схемой требует совпадения номера корпуса и кампуса на Карла Маркса. У спортзала исходное короткое название и полный адрес неоднозначны: автоматическая привязка отключена.

## Мероприятия

Источник — [официальные объявления УУНиТ](https://uust.ru/events/). Встроенная подборка в `app/data/events.json` составлена вручную по текстам анонсов, проверенным 27 сентября 2026 года. Дата публикации не используется как дата проведения. Каждое событие содержит собственную ссылку.

Для обновления без изменения экранов отредактируйте JSON и импортируйте его через **Профиль → Импорт мероприятий**. Импорт заменяет подборку на конкретном устройстве и помечается «Импорт команды». В том же окне можно вернуть встроенную подборку. Ограничения: до 300 событий, файл до 512 КБ.

```json
{
  "schemaVersion": 1,
  "events": [
    {
      "id": "team-demo-event",
      "title": "Пример события для проверки импорта",
      "date": "2026-09-30",
      "time": "17:00",
      "endTime": "18:00",
      "category": "Встреча",
      "description": "Демонстрационные данные. Не реальный анонс.",
      "place": "Место не подтверждено",
      "buildingId": null,
      "source": "",
      "demo": true,
      "accent": "lime"
    }
  ]
}
```

Время задаётся для Уфы. Если время неизвестно, используйте `null`, не придумывайте его. `buildingId` — строка от `"1"` до `"9"`, только когда место подтверждено; иначе `null`. `accent`: `lime`, `blue` или `peach`. Ссылка `source` при наличии должна начинаться с `https://`. Неизвестное время исключает уверенное заключение об отсутствии пересечений.

Автоматического сбора новых событий пока нет. Напоминания используют сохранённые события с известным временем; учитываются избранное и запись на встречи. Серверная push-доставка не подключена.

## Студенческие объединения

`app/data/clubs.json` содержит все 35 объединений из [каталога УУНиТ](https://uust.ru/student-unions/), просмотренного 29.09.2026. Четыре прежние карточки сохранены, добавлена 31 новая. У каждой карточки указан источник; отдельные ссылки VK/Telegram необязательны и не подставляются по догадке. Для новых карточек без фотографии показывается монограмма. Поиск учитывает название, направление и краткое описание.

## Напоминания и семестровый вид

`app/notifications.js` формирует очередь по времени Уфы из загруженных недель занятий и избранных/посещаемых событий. Неточное время исключает напоминание; тихие часы проверяются по времени отправки, а не начала занятия. Одинаковые начало и конец тихих часов означают отсутствие ограничения. Очередь ограничена 5000 будущими напоминаниями на период до 370 дней.

`ReminderReceiver.java` хранит очередь локально, назначает ближайшее напоминание через AlarmManager и после доставки назначает следующее. При закрытии WebView очередь сохраняется. Системное принудительное завершение приложения и ограничения производителя могут препятствовать работе; после следующего запуска очередь восстанавливается. Отключение в приложении отменяет запланированные и показанные уведомления. Для изменения данных нужно открыть приложение и обновить источник.

«Семестр» показывает все учебные недели ответа API, включая недели с изменяющимся составом занятий. Идентификатор `241` покрывает учебный год, поэтому приложение не назначает непроверенные даты начала и конца зимнего/летнего семестра.

## Карта и фотографии

Основа: архив `ugatu_interactive_map_1.rar`, предоставленный командой. В `app/data/buildings.json` сохранены контуры и взаимное расположение девяти корпусов. Визуальное оформление, масштабирование и взаимодействие реализованы заново. Фотографии находятся в `app/assets/buildings/`.

Это **схема без географической привязки**. Приложение не запрашивает GPS и не рисует непроверенные пешеходные маршруты. Кнопка городских карт открывает поиск по адресу и корпусу. Необходима проверка входов и проходов командой на территории.

Контуры территории сохраняются в `buildings.json`. `sceneOutline` для корпусов 6 и 7 повторяет вершины их SVG-контура и используется для вписывания планов. Поэтажные планы, помещения и граф подключаются через `app/data/maps.json` при сборке либо импортом JSON в приложении. В наборе 10 планов корпусов 6 и 7 из материалов команды и CampusWay. Разворот и подгонка выполняются только при отображении: исходные координаты графа и веса рёбер сохраняются. Формат, источники, проверки и ограничения описаны в [инструкции по картам](MAPS.md).

Скрипт `tools/prepare_data.py` использовался для первоначальной обработки архива и снимков в локальном `research/`. Этот каталог не входит в Git. Обычная сборка приложения не требует повторного запуска скрипта.

Права на дальнейшее публичное распространение фотографий и схемы команда должна подтвердить у владельцев материалов. Репозиторий публичный по решению владельца; права записи предоставляются только команде.
