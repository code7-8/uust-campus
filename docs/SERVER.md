# Общая афиша на ноутбуке

Карта и расписание в APK работают без этого сервера. Сервер нужен для аккаунтов, прав организатора и общей афиши.

1. Распакуйте ZIP сервера из Releases или откройте корень репозитория. Нужен Python 3.10+; дополнительных библиотек нет.
2. Запустите `start-server.cmd`. При первом запуске задайте логин, имя и пароль администратора. Пароль вводится без отображения символов. Запомните его: готового общего пароля нет.
3. Включите мобильную точку доступа Windows и подключите к ней телефоны. Окно сервера оставьте открытым.
4. В APK откройте **Профиль → Сервер команды** и введите `http://192.168.137.1:8787`, затем «Проверить и подключить».
5. Войдите под администратором. Остальные участники регистрируются с телефонов. В профиле администратора откройте **Управление правами → Разрешить события** возле нужного участника.
6. Организатор нажимает **Создать событие**. Общая афиша обновляется у подключённых пользователей, включая гостей, каждые 20 секунд; есть кнопка «Обновить».

Если Windows запросит доступ для Python, разрешите его для своей частной сети. Если соединения нет, проверьте общий Wi-Fi, окно сервера и адрес IPv4 ноутбука через `ipconfig`. В этой сборке HTTP разрешён на `192.168.137.1` (точка доступа Windows) и `192.168.31.245` (адрес ноутбука во время разработки), также на адресах локальной разработки. Другой адрес потребует точечного изменения конфигурации Android и клиента либо HTTPS. Не используйте адрес VPN.

При точке доступа **телефона**, к которой подключён ноутбук, адрес ноутбука может быть другим. Адрес показывается в окне сервера. Не подставляйте `localhost` на телефоне: это адрес самого телефона.

Локальный HTTP предназначен для показа в доверенной общей сети; трафик, включая вход, не зашифрован. Используйте отдельные демонстрационные пароли. Для подключения из разных сетей понадобится HTTPS-сервер; его адрес меняется в профиле без переустановки APK. Открывать порт Python напрямую в интернет не требуется.

Данные сохраняются в `server/data/campus.sqlite` на ноутбуке. Для резервной копии остановите сервер (`Ctrl+C`) и скопируйте каталог `server/data` в защищённое место. Не отправляйте базу в GitHub. ZIP релиза не содержит аккаунтов и базы.

Для дополнительного администратора запустите `python server/server.py --init-admin`. Публичная регистрация всегда создаёт обычного участника; только администратор выдаёт право публикации. Организатор изменяет свои события; администратор — любые.

Браузерная страница на порту 8787 поддерживает аккаунты и общую афишу, но не проксирует расписание. Для разработки всех экранов используйте `python tools/preview.py`, а в профиле укажите сервер `http://127.0.0.1:8787`.
