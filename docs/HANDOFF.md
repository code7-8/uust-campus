# Передача работы: сборка 0.3.2

Ветка `codex/continuous-map`, основа — `main` после PR №7 (`929fa4f`). Владелец разрешил после завершения сразу объединить новую версию с `main`. [Изменения и ограничения](RELEASE_0.3.2.md).

Карта использует общие координаты территории. `app/map/scene.js` получает габариты контуров SVG и вписывает планы без изменения пропорций; это условное отображение, не геопривязка. `sceneSvg` рисует территорию и по одному выбранному этажу каждого корпуса. Масштаб меняет видимость слоёв без замены SVG во время жеста. Выбранные этажи сохраняются отдельно для каждого корпуса. Размеры значков учитывают преобразования вложенных SVG-групп.

`view.js` разделяет явное приближение выбранного места и свободное движение карты. Изменение карточек не должно автоматически возвращать камеру к маршруту. При добавлении точной привязки менять преобразования отображения отдельно от проверенного графа маршрутов.

По просьбе владельца тесты, браузер и телефон в этой работе не запускались. Команде проверить приближение/отдаление корпусов 6 и 7, смену этажей, поиск кабинета и межкорпусный маршрут на телефоне.
