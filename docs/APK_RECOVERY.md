# Восстановление версии из APK

28 сентября 2026 пользователь передал `uust-campus-0.2.0.apk` из Downloads с несохранёнными изменениями сокомандника.

SHA-256: `c782f4eedd9a88eefa425d558f4d6a77cd5339c77cbb64d220da2affe3f8dcee`.

База сравнения: `8b092bf`, ветка `feat/final-demo`. Из `assets/` извлечены файлы интерфейса; после нормализации CRLF содержательные изменения обнаружены в восьми файлах:

- `app/data/buildings.json`
- `app/map/campus.js` (новый)
- `app/map/data.js`
- `app/map/gestures.js`
- `app/map/map.css`
- `app/map/routing.js`
- `app/map/svg.js`
- `app/map/view.js`

Остальные ресурсы совпадают с базовой версией, включая планы этажей, темы и клиент сервера. Восстановленные файлы сохранены отдельным коммитом до дальнейших исправлений.

Двоичные AndroidManifest.xml и resources.arsc совпадают с локальной сборкой 0.2.0. classes.dex отличается. Сравнение дизассемблирования `dexdump -d` после исключения адресов и индексов таблиц показало единственное различие: распределение регистров в методе `response`, с теми же вызовами и значениями. Семантических изменений Android-оболочки не обнаружено; оставлены её исходники из базы. Это не побайтовое восстановление сборочного окружения сокомандника.

Восстановленная карта поддерживает маршруты между корпусами через переходы и отдельно внутренние маршруты. Уличных связей, привязки входов к внутренним этажам и дверей большинства кабинетов в APK нет. Следующая задача: показывать номера кабинетов на этажах, дать общий выбор начала и конца маршрута, учитывать уличные пути с явным происхождением данных.

## Доработка 0.2.1

- Сразу видны номера и горизонтальный список кабинетов выбранного этажа.
- Общие селекторы начала и цели: корпус, кабинет, лестница; обмен точек.
- По исходным планам дополнены двери и коридоры: 44 из 47 помещений подключены к графу на этажах 3–5 корпуса 6. Исправлены границы помещений 311, 313, 315. Для 420 неясен вход, 516 и 522 служебные — маршрут не обещается.
- Dijkstra сравнивает условную стоимость пути. Масштабы изображений нормализуются, лестница имеет отдельную стоимость. Метры и минуты не показываются.
- Режимы: короткий по схеме, через переходы, через улицу. Уличная альтернатива — **ориентировочный обход по внешнему периметру контуров**, не полученный из проверенного пешеходного графа. Он не учитывает ограждения и доступность ворот.
- Связь корпуса с лестницей этажа и выход на улицу — явные самостоятельные участки без геометрии. Поэтому маршрут корпус → кабинет ещё не является непрерывной навигацией от двери до двери.
- Между кабинетами одного корпуса используются только размеченные внутренние связи, без ложного сокращения через неизвестный первый этаж.

Для завершения уличной навигации команда должна указать реальные открытые входы, связь с лестницами и проходимые дорожки. Вопрос пользователю отправлен, ответа на момент реализации нет.
