## Реализовано

Темы и иконки, гостевой режим, сервер Python без внешних зависимостей, SQLite, роли user/organizer/admin, общие мероприятия. Администратор создаётся только локально при первом запуске `start-server.cmd`, затем выдаёт права в приложении.

Карта: 9 корпусов, 3 архивных этажа корпуса 6, 47 кабинетов (44 подключены к графу), 102 внутренних связи. Общий выбор начала/цели, смена этажей, маршрут кабинет → кабинет и корпус ↔ кабинет. Уличный обход приблизителен; точные входы, нижние этажи и дорожки ещё не предоставлены. Самостоятельные участки выделены в шагах без выдуманной геометрии.

## Что проверить команде

1. Установить APK 0.2.2, проверить карту на своём телефоне. Браузерная проверка не заменяет проверку Android.
2. Уточнить открытые входы и проходимость улицы. Пользователю отправлен вопрос; ответа пока нет. Заменить ориентировочную схему и ручные переходы точными связями.
3. Проверить на месте архивные этажи, соответствие лестниц и дверей. Служебные 516/522 и неясный вход 420 не маршрутизируются.
4. При необходимости обновить импортированный старый набор через «Вернуть встроенную схему»: пользовательский импорт не перезаписывается автоматически.
5. Запустить общий сервер, создать своего администратора и подключить телефоны по одной Wi-Fi сети.

SDK: `F:\void_oneplus\.tools\android-sdk`, JDK: `F:\void_oneplus\.tools\jdk\jdk-21.0.12.1+1`. Сборщик `tools/build.ps1`. Старый ключ `tools/signing/campus-demo.jks` нужен для обновлений — не коммитить.

Проверки: `node --test tests/core.test.js tests/map.test.js`, `node tools/validate-maps.mjs`, `python -m unittest discover -s server -p test_server.py -v`.

HTTP разрешён только localhost, 127.0.0.1, 10.0.2.2, 192.168.137.1 и 192.168.31.245. Интернет-сервер должен иметь HTTPS. Глобальное разрешение HTTP ранее отклонено автоматической проверкой, не повторять.

Не использовать `moevm`. База, пароли, токены и ключ подписи исключены из Git. APK публиковать через Releases. Main не изменять без согласования с командой; текущая работа публикуется веткой/PR.
