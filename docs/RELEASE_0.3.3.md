# Кампус 0.3.3

По замечанию тестировщика исправлена ориентация планов корпуса 7 на единой карте: этажи отражены по горизонтали, чтобы помещения располагались со стороны улицы. Корпус 6 не отражается.

Исправлено смещение планов относительно корпусов: планы корпусов 6 и 7 вписываются в основное крыло вдоль улицы. Ранее использовался центр общего габарита здания, включавшего боковые крылья и пустое пространство двора. Пропорции планов сохранены.

Стены, двери, помещения и линия маршрута преобразуются вместе; номера кабинетов, значки и подписи остаются читаемыми. Поиск и приближение к точкам маршрута используют то же преобразование. Исходные данные и связи графа не менялись.

Размещение по-прежнему схематичное: точное совмещение каждого крыла по измеренным ориентирам ещё не выполнено. Тесты и браузерная проверка не запускались по просьбе владельца; проверку на телефоне выполняет команда.
