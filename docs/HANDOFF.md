- `server/server.py`: первая реализация сервера на Python 3.10+ без внешних зависимостей, SQLite, scrypt, сессии, роли, общие мероприятия, локальная настройка администратора. Ещё требуется проверка и интеграция клиента.
- `start-server.cmd`: запуск и первоначальная настройка администратора.
- `app/assets/uust-logo.png`: исходный значок пользователя. `uust-logo-green.png`: вариант ImageGen со светло-зелёным фоном и белым знаком.
