## Этап 1

Карта занимает всю высоту экрана, поиск и кнопки плавают поверх неё. Пустая нижняя карточка скрыта. Карточка выбранного места закрывается явной кнопкой; камера учитывает перекрывающий интерфейс при выборе точки. Геометрия девяти корпусов выровнена без изменения их идентификаторов и связей с расписанием. Сохранены две темы, поиск, этажи и внутренние маршруты.

## Следующий этап

Добавить отдельную схему связей между корпусами и выбор начала/конца маршрута. Схему команды сохранить в `docs/map-reference-2026-09-27.jpg`. Переход 5–6 упомянут командой со ссылкой на панорамы Яндекса, но независимо не проверен: показывать пунктиром и учитывать в маршруте только при явном выборе. Остальные связи сверять с приложенной схемой. Не выдавать маршрут между корпусами за проверенный маршрут по конкретным этажам, не придумывать расстояния, время или доступность дверей.

## Проверка

`node tools/validate-maps.mjs`

`python tools/preview.py --port 4173`, затем `node tests/map-layout-ui.mjs` и `node tests/map-ui.mjs` с установленным Playwright. Браузерные тесты используют отдельный Chrome и блокируют API расписания. Скриншоты — в игнорируемом `artifacts/`.

Локально JDK/SDK и вспомогательные скрипты находятся в игнорируемом `artifacts/build-support/` основной папки проекта. Ключ подписи — `tools/signing/campus-demo.jks`, вне Git. На другом компьютере нужны собственные пути к инструментам; для совместимого обновления APK нужен тот же ключ. Последний APK до этих изменений — prerelease `v0.2.0-dda2dae`.

Не обращаться к запрещённой организации из AGENTS.md. Не добавлять ключи и временные файлы в коммиты. Законченные этапы коммитить и отправлять в указанную ветку на GitHub.
