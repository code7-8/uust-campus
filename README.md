# Кампус

Android-приложение для хакатона «Умный помощник для кампуса». Основной сценарий: **выбрать группу → увидеть ближайшую пару → открыть нужный корпус на карте**.

Текущая опубликованная сборка: **0.3.2**, Android **8.0+**. Это студенческий прототип, а не официальное приложение университета.

### Доработки 1 октября: этажи, сервер по умолчанию и уведомления

- Этажи 4 и 5 корпуса 6 заканчиваются у края верхнего выступа. Этаж 4,5 занимает всю верхнюю часть, включая левый угол, и соединяется с 4-м через лестницу у лаборатории 407. Остальные этажи сохранены. Кнопки этажей больше не сбрасывают масштаб и положение камеры.
- Адрес `https://139.100.239.210.sslip.io` встроен по умолчанию: после установки не нужно настраивать сервер перед входом или созданием встречи. Явно сохранённый адрес можно по-прежнему изменить в профиле.
- Исправлена потеря уведомления при обновлении афиши после назначенного времени: очередь ждёт доставки до начала события, отправленные напоминания не дублируются. Добавлена кнопка **Проверить уведомление**. [Проверка на телефоне](docs/NOTIFICATIONS.md).
- Обложки клубов подстраиваются под ширину экрана; исправлен MIME-тип встроенных WebP в Android. Найдены официальные источники ещё восьми обложек, но загрузка файлов с uust.ru обрывается на TLS-соединении. Новые фото пока не включены; сохранены исходные три и обложки с буквами. Повторяемый загрузчик: `node tools/fetch-club-images.mjs` (можно указать ID клубов).

Проверено: 50 JavaScript-тестов, 17 серверных тестов, оба сценария Chrome, валидатор 10 этажей и компиляция Java с API 35. Браузерная проверка разрешённого уведомления моделирует системный API; она не подтверждает фоновую доставку на Android.

Изменения относятся к исходникам; для телефона нужен новый APK. Фоновая доставка Android требует проверки на устройстве, которое в этой сессии отсутствует.

### Доработки 30 сентября: публичный сервер и карта

Backend подготовлен к одному публичному HTTPS-адресу для телефонов из разных сетей. Сохранены `server/server.py`, `/v1` API, SQLite и текущий клиент. Добавлены Waitress, конфигурация окружения, неинтерактивное создание администратора, health-check, лимиты запросов за доверенным прокси, постоянный диск и согласованная резервная копия базы. Готовы `Dockerfile`, `render.yaml`, `.env.example` и [инструкция развёртывания](docs/SERVER.md). Сервис в облаке автоматически не создаётся; реальный HTTPS URL выдаст выбранный хостинг.

Карта обновлена по уточнению команды: этажи 1–3 корпуса 6 и 1–4 корпуса 7 расширены по основной части здания; 4 и 5 этажи корпуса 6 используют одну основную прямоугольную часть. Крыло 4,5 повёрнуто на 90° вправо относительно прежнего вида, помещено в верхний выступ рядом с указанной лестницей и показано вместе с 4 этажом. Добавлена связь с новой лестницей выше «лестницы у левого торца». Подземный переход сдвинут вправо, связан с лестницами первых этажей и получил приоритет в маршрутах. Убрана обратная связь между высотой карточки и выбором корпуса камерой. Геометрия остаётся схемой, а не обмерным планом.

Для браузерных проверок: `npm ci`, затем `npm run test:browser` (Chrome или `PLAYWRIGHT_CHANNEL=chromium`; переменная `PYTHON` — интерпретатор с `server/requirements.txt`). Проверки сервера: `python -m unittest discover -s server -p "test_*.py" -v`. Эти исходники ещё не включены в опубликованный APK 0.3.2.

Проверка доработки: 45 JavaScript-тестов, 17 серверных тестов, два сценария Chrome (общая афиша и карта), валидатор карт, компиляция Java приложения и instrumentation-теста с API 35. Docker-образ и Android instrumentation не запускались: Docker и тестовый эмулятор отсутствуют. Проверки в браузере не заменяют проверку APK на телефоне.

В исходниках от **29.09.2026** добавлены изменения ниже. Опубликованный APK 0.3.2 ещё не содержит эти изменения; новый APK в рамках этой доработки не собирался.

### Доработки 29 сентября

- Все 10 поэтажных планов развёрнуты на **180°**. Масштаб рассчитывается по геометрии помещений, без пустых полей изображения, с учётом вогнутого контура корпуса. Этажи 4, 4,5 и 5 корпуса 6 также вписываются в контур. Номера, поиск, двери и линии маршрутов согласованы с новым расположением. Подгонка схематическая и может менять пропорции плана; расстояния маршрутов от неё не зависят.
- На карте и в маршрутах появился **подземный переход 6–7**, обозначенный пунктиром. Основание — сообщение команды; точные входы и спуск на поэтажных планах пока не размечены. Режим «По улице» исключает переход.
- **Уведомления** открываются через колокольчик или профиль. Можно включить напоминания о парах, избранных событиях и встречах с записью, выбрать 5/10/15/30/60 минут до начала и тихие часы по времени Уфы. Настройки сохраняются; смена группы, времени события и отключение категории обновляют очередь.
- Android сохраняет очередь напоминаний и продолжает её при закрытом WebView, восстанавливает после перезагрузки и обновления приложения. Для Android 13+ запрашивается разрешение уведомлений; точное время включается отдельно через «Будильники и напоминания». Без него Android может задерживать доставку. В браузере напоминания действуют только при открытой странице. Новые данные требуют обновления расписания/афиши; серверных push-уведомлений нет.
- Каталог расширен с 4 до **35 объединений** по [официальному списку УУНиТ](https://uust.ru/student-unions/): танцы, музыка, театры, туризм, экология и клубы по интересам. Есть поиск и фильтр по направлению. Ссылки на сообщества добавлены там, где они подтверждены; в каждой карточке есть страница университета с контактами.
- В расписании появился вид **«Семестр»**: все недели и занятия из загруженного ответа, с раскрытием недель и карточками пар. Данные доступны офлайн после загрузки. Для встроенного снимка ТОП-106Б это 17 учебных недель. Период берётся из недель источника, календарные границы семестра не придумываются.

Проверено для этих изменений: **41 тест**, валидатор карт, DOM-проверка новых экранов и настроек, отрисовка всех 10 этажей, компиляция Java с Android API 35. Полноценный браузер и Android-устройство в этой сессии не были доступны; фактическую фоновую доставку уведомлений нужно проверить на телефоне.

## Возможности

- Бело-фиолетовая и зелёная темы с переключением в профиле.
- Необязательный вход; администратор выдаёт право публикации общей афиши.
- Выбор группы из справочника УУНиТ, сохранение локального профиля.
- Настоящее расписание: день, неделя, семестр, ближайшая пара, преподаватели и аудитории.
- Учебные недели 2026/2027 и время Уфы, `Asia/Yekaterinburg` (UTC+5).
- Отдельный кеш расписания каждой группы; встроенный снимок для ТОП-106Б.
- Карта девяти корпусов: единое полотно территории и этажей. При приближении появляются кабинеты, при отдалении — номера корпусов. Выбор этажа запоминается для каждого корпуса. Поиск, жесты масштаба и перемещения, фотографии и избранное сохранены.
- Импорт проверяемого JSON-набора этажей, локальное хранение, поиск и маршруты по графу. Планы этажей 1–5 корпуса 6, связанное с 4 этажом крыло «4,5» и этажи 1–4 корпуса 7: 121 помещение, 111 с размеченной дверью. Начало и конец выбираются через поиск. Участки маршрута переключаются кнопкой «Далее»; выбор корпуса или этажа не сбрасывает маршрут. Уличный обход ориентировочный.
- Студенческая жизнь: клубы, официальные события и встречи студентов; создание своих встреч, общая запись с лимитом мест, избранное, проверка пересечений с парами и переход на карту.
- Импорт мероприятий из JSON и открытие формы события в системном календаре.

## Установка APK

Загрузите `uust-campus-0.3.2.apk` из раздела **Releases** репозитория, перенесите на телефон и откройте файл. Android может запросить разрешение на установку из используемого браузера или файлового менеджера.

Сборка подписана локальным ключом для тестирования. Ключ хранится только у разработчика: `tools/signing/campus-demo.jks`. Для обновления установленного приложения последующие APK необходимо подписывать тем же ключом.

## Разработка

Интерфейс написан на JavaScript, HTML и CSS без внешних библиотек времени исполнения. Android-оболочка на Java загружает встроенные ресурсы в WebView и получает JSON через HTTPS. Основные экраны работают самостоятельно. Для необязательных аккаунтов и общей афиши есть сервер Python: [инструкция запуска](docs/SERVER.md).

Быстрый предпросмотр на компьютере — Python 3.10+:

```powershell
python tools/preview.py
```

Откройте `http://127.0.0.1:4173`. Локальный сервер проксирует только предусмотренные запросы расписания. Для обновления нужен интернет; встроенные данные открываются без него.

## Сборка Android

Нужны Windows, PowerShell, Python, JDK 17 или 21, Android SDK Platform 35 и Build Tools 35.0.0. Android Studio и Gradle для текущего сборщика не обязательны.

```powershell
$env:JAVA_HOME = 'C:\path\to\jdk-21'
$env:ANDROID_HOME = 'C:\path\to\android-sdk'
.\tools\build.ps1
```

Или передайте пути явно:

```powershell
.\tools\build.ps1 -Sdk 'C:\path\to\android-sdk' -Jdk 'C:\path\to\jdk-21'
```

Результат: `artifacts/uust-campus-0.3.2.apk`. Сборщик использует временный каталог с ASCII-путём и нормализует имена ZIP-записей: это решает обнаруженные проблемы Windows-инструментов Android с кириллицей и вложенными ресурсами.

При отсутствии переменных скрипты содержат резервные пути окружения первоначальной разработки. На другом компьютере задайте свои `JAVA_HOME` и `ANDROID_HOME`.

## Проверки и текущий статус

Для версии **0.3.2** по просьбе владельца проекта тесты и проверка в браузере не запускались. Ручную проверку APK выполняет команда. Ниже — команды для дальнейшей проверки и история предыдущих сборок.

```powershell
npm test
node tools/validate-maps.mjs
```

До первой передачи APK прошли 12 проверок логики: календарь, часовой пояс, поиск, соответствие корпусов, пересечения событий, импорт и обработка неверного ответа источника. В браузере проверены реальное обновление расписания и основные экраны. APK собирается, подписывается, устанавливается на Android 15; первый экран проверен на эмуляторе после исправления упаковки ресурсов.

**Полная проверка приложения на телефоне ещё не завершена.** По просьбе команды дальнейшие тесты остановлены для быстрой передачи APK. Подготовленный сценарий Android instrumentation ещё не запускался; его наличие не означает успешного прохождения:

```powershell
.\tools\test-android.ps1 -Serial emulator-5554
```

Запускайте его только на отдельном тестовом эмуляторе: он очищает локальный профиль этого приложения и временно отключает сеть эмулятора. Онлайн-обновление именно внутри Android APK и системные диалоги календаря/импорта требуют завершения проверки.
