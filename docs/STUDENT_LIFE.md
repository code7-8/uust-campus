# Студенческая жизнь

Ветка `codex/student-life` начата от актуальной `origin/main` (`78572f4`).
Изменения карты из другой рабочей ветки здесь не смешиваются.

## Сервер

Обычный аккаунт создаёт `kind: student`, редактирует и удаляет свои встречи.
`kind: official` доступен только организатору и администратору. Роль выдаёт
администратор выбранного сервера; это не проверка студенческого билета или SSO УУНиТ.
Старые записи без `kind` считаются официальными, поскольку ранее публикация
была доступна только организаторам. При первой загрузке Store добавляет таблицу
attendance без изменения существующих пользователей и событий.

- `GET /v1/events`: публичные счётчики; с Bearer — ещё и личный `viewerGoing`.
- `POST /v1/events/{id}/attendance`: записаться, повторный запрос безопасен.
- `DELETE /v1/events/{id}/attendance`: отменить участие.
- `capacity: null` — без лимита, иначе целое 1–10000.
- SQLite-транзакция защищает последнее место от одновременной записи и
  запрещает уменьшить лимит ниже количества участников. Удаление события
  удаляет его записи. Имена участников не публикуются.
- Время — Уфа (UTC+5). На завершившееся событие записаться нельзя.

Проверка: `python -m unittest discover -s server -v`.

## Интерфейс

Вкладка **Жизнь** содержит клубы, события УУНиТ и встречи студентов.
На главной **Сегодня в кампусе** смешивает клуб, ближайший анонс университета
и ближайшую встречу студента. Даты будущих событий видны в карточках.
Кнопка **Я пойду** и общий счётчик доступны у событий сервера (в том числе
официальных). Для встроенных редакционных анонсов сохранена внешняя регистрация
по ссылке источника: локальный файл не подменяет официальную регистрацию.

Редактор сохраняет название, описание, организатора, дату/начало/конец по Уфе,
место, корпус, аудиторию, этаж и необязательный лимит мест. Известные аудитории
связываются с устойчивыми ID карты. **Показать маршрут** сразу выбирает цель;
начало пользователь указывает сам. Если комнаты нет в наборе карты, цель —
корпус, а исходная подпись места остаётся доступной. Несовпадающий этаж не
заменяется другой комнатой. Карта, её архивные ограничения и сведения о
доступности остаются прежними.

Каталог из четырёх клубов встроен в приложение и доступен офлайн. Описания
написаны кратко по первичным источникам, контакты проверены 28.09.2026:

- [Final Round](https://uust.ru/departments/final-round/) — настольные игры;
- [Икар](https://uust.ru/departments/ikar/) — туризм;
- [Brain Bricks](https://uust.ru/departments/brain-bricks/) — разработка игр;
- [Гротеск](https://uust.ru/departments/grotesk/) — театр.

VK и Telegram взяты со страниц клубов, персональные контакты руководителей
не перенесены. Три фотографии — исходные файлы УУНиТ без обработки,
`imageSource` хранит адрес оригинала; сайт отдаёт WebP даже по URL `.jpeg`.
Для Brain Bricks на странице нет фотографии: используется текстовая обложка.
Данные редактируются в `app/data/clubs.json`; это подборка для знакомства,
не полный перечень всех объединений. У каждого клуба есть ссылка на источник.

## Запуск и проверки

Для общих встреч обновите и запустите сервер этой ветки; подключение описано
в [SERVER.md](SERVER.md). Все устройства должны выбрать один сервер.
Работа без сети не создаёт фиктивную запись: остаются сохранённые данные,
а публикация и участие требуют успешного ответа сервера.

```sh
node --test tests/core.test.js tests/map.test.js tests/student-life.test.js
python -m unittest discover -s server -v
node tools/validate-maps.mjs
```

Браузерная проверка: нужен Python 3.10+, Node, модуль Playwright и установленный
Chrome. При нестандартном расположении укажите `PYTHON` и `NODE_PATH`.
Запуск: `node tests/student-life.browser.cjs`. Тест сам поднимает сервер на
случайном локальном порту с временной базой и закрывает его. Два независимых
браузерных контекста проверяют регистрацию, создание/правку/удаление встречи,
общий лимит мест, запись/отмену, маршрут в кабинет, главную и офлайн-клубы.
Переход VK перехватывается: реальных обращений к сообществу тест не делает.
Скриншоты сохраняются в игнорируемый `artifacts/student-life-tests/`.

Пройдено: 32 Node-теста, 9 серверных тестов, валидация карты и браузерный
сценарий. Интерфейс проверен при ширине 320, 390 и 580 px, в обеих темах.
Физическое Android-устройство и реальная сеть нескольких телефонов не проверены.

## Продолжение с другого компьютера

Получите ветку `codex/student-life` из `code7-8/uust-campus` и начните с этого
файла. Ветка содержит сервер, данные, интерфейс и воспроизводимые тесты;
локальная база, учётные данные, APK и ключи подписи в Git не добавлялись.
Отдельный публичный сервер эта задача не разворачивает. Для эксплуатации
в интернете остаётся выбрать HTTPS-размещение; инструкции есть в SERVER.md.
Не использовать материалы или репозитории `moevm` и не менять доступ/видимость
репозитория. Готовые APK размещаются только в GitHub Releases.
