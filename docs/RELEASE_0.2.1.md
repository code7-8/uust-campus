# Кампус УУНиТ 0.2.1

**Для установки рядом с присланной версией выбирайте `uust-campus-0.2.1-parallel.apk`.** Его ярлык называется «Кампус УУНиТ 0.2.1». У APK сокомандника другой сертификат подписи, поэтому обычный APK не обновит его поверх. Параллельная сборка имеет отдельный идентификатор приложения и отдельные настройки; старое приложение и его данные сохраняются. Обычный `uust-campus-0.2.1.apk` предназначен для обновления наших прежних сборок с тем же ключом.

Из APK команды восстановлены изменения карты. Номера кабинетов видны при открытии этажа, ниже есть список помещений. Можно выбрать обе точки маршрута: корпус, кабинет или лестницу, поменять их местами и переключить способ движения.

Встроены архивные планы этажей 3–5 корпуса 6: 47 помещений, маршруты к 44 из них. Маршруты между кабинетами соединяют двери, коридоры и лестницы. Для 6-420 неясен вход; 6-516 и 6-522 служебные — маршруты к ним не заявлены.

Уличный вариант ориентировочный, построен по внешнему периметру схемы. Он сравнивается с переходами по условной стоимости, без метров/минут. **Открытые входы, дорожки и ограждения ещё нужно уточнить.** Неизвестные участки между корпусом и этажом описаны словами и не рисуются как подтверждённый проход. Это ещё не непрерывная навигация от наружной двери до кабинета.

В сборку также входят ранее добавленные бело-фиолетовая/зелёная темы, соответствующие иконки, необязательный аккаунт, роли и общий сервер мероприятий. ZIP сервера содержит инструкцию `docs/SERVER.md`; личных аккаунтов, паролей и базы в нём нет.

Проверено: 26 тестов JavaScript (включая все 1936 пар подключённых кабинетов), 5 серверных тестов, валидация карты, браузерные сценарии на размере 390×844, сборка APK и подписи v2/v3. Установка этой версии на физический телефон пока не проверена.

Если ранее импортировали старый JSON, выберите на карте «Добавить планы → Вернуть встроенную схему». Собственные импортированные данные при обновлении APK не заменяются автоматически.
