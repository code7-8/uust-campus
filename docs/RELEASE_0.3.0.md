# 0.3.0 — планы корпусов 6 и 7 и студенческая жизнь

Основа — опубликованная ветка `codex/student-life`, коммит `1120a93`.
Её файлы `app/` сверены с присланным командой APK 0.2.2: содержимое совпадает
после нормализации переносов строк. Включены клубы, студенческие встречи,
общая запись на мероприятия и изменения сервера. Расширение карты сделано поверх этой версии.

## Карта

В наборе **10 схем, 121 помещение**, у **111** размечена дверь и локальный путь.
Это девять обычных этажей и отдельный участок «4,5», а не десять полных этажей.

- Новые планы обведены по фотографиям команды от 28.09.2026. Видны номера,
  контуры помещений, двери, коридоры, лестницы и основные ориентиры.
- Доступны поиск и маршруты между размеченными кабинетами, этажами и корпусами.
  Новые первые этажи соединены с верхними через соответствующие лестницы на планах.
  Переход от схемы территории теперь ведёт к вестибюлю первого этажа,
  без самостоятельного «перехода» сразу на верхний этаж.
- Внутри отдельного крыла «4,5» путь строится от известного местного старта.
  С обычными 4/5 этажами крыло не соединено: подпись фотографии не определяет
  точную лестницу. В интерфейсе есть пояснение.
- Буфет корпуса 6 на втором этаже не добавлен: команда подтвердила, что его больше нет.
- Повторные номера 6-216, 7-109, 7-205/206 и 7-305/306 сохранены отдельными
  вариантами. При неоднозначной ссылке из мероприятия приложение не выбирает
  комнату автоматически. Нужно выбрать объект поиска или передать `locationId`.
- Старые `cw-*` идентификаторы сохранены. Собственный импорт карт не перезаписывается.
  Если на устройстве выбран старый импорт: **Карта → Добавить планы → Вернуть встроенную схему**.

## Что ещё не покрыто

Не добавлены корпуса 1, 2, 8, 9 из нового экспорта: их материалы сохранены локально
для следующей разметки. Фото дополнительного крыла 5 этажа корпуса 6 не содержит
номеров кабинетов; оно тоже осталось в очереди. Шестой этаж корпуса 6 закрыт по
сообщению команды, его плана нет. Не все помещения на новых планах имеют номера
или однозначные публичные двери; служебные объекты не открыты как проходы.

Фото эвакуационных планов не подтверждают ежедневный доступ. Межэтажные связи
имеют статус `plan`, а не `open`; доступность на месте и пути без ступеней не заявлены.
GPS, точные входы на уличной схеме и проверенный граф дорожек по-прежнему отсутствуют.
Уличные участки ориентировочные, связь территории с входом описана ручным шагом.

## Воспроизведение

```powershell
python tools/prepare_survey_maps.py
node tools/validate-maps.mjs
node --test tests/core.test.js tests/map.test.js tests/student-life.test.js
python -m unittest discover -s server -v
powershell -ExecutionPolicy Bypass -File tools/build.ps1
powershell -ExecutionPolicy Bypass -File tools/build.ps1 -SideBySide
```

Генератор содержит разметку и номера исходных фото; повторный запуск даёт тот же
JSON. Полный экспорт Telegram, переписка и фотографии остаются локальными и
не входят в Git или APK. В приложение включена только производная векторная схема.

Android: 0.3.0, versionCode 5. Обычный пакет — `ru.uust.campus`, параллельный —
`ru.uust.campus.preview`. Обновление возможно только поверх APK с тем же ключом.
Для APK сокомандника с другим ключом используйте параллельную сборку, сохраняя старую.

Проверяются логика маршрутов, неоднозначные номера, изоляция крыла, сервер и
мобильный интерфейс в браузере. Проверка на физическом Android остаётся за командой.
