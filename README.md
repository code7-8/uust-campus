# Кампус УУНиТ

Android-приложение для хакатона «Умный помощник для кампуса». Основной сценарий: **выбрать группу → увидеть ближайшую пару → открыть нужный корпус на карте**.

Текущая сборка: **0.2.2**, Android **8.0+**. Это студенческий прототип, а не официальное приложение университета.

Отчёт новой сборки: [0.2.2 и ограничения маршрутов](docs/RELEASE_0.2.2.md). Восстановление версии команды: [APK_RECOVERY.md](docs/APK_RECOVERY.md).

## Возможности

- Бело-фиолетовая и зелёная темы с переключением в профиле.
- Необязательный вход; администратор выдаёт право публикации общей афиши.
- Выбор группы из справочника УУНиТ, сохранение локального профиля.
- Настоящее расписание: день, неделя, ближайшая пара, преподаватели и аудитории.
- Учебные недели 2026/2027 и время Уфы, `Asia/Yekaterinburg` (UTC+5).
- Отдельный кеш расписания каждой группы; встроенный снимок для ТОП-106Б.
- Карта девяти корпусов: поиск сверху, отдельная нижняя карточка, жесты масштаба и перемещения, фотографии и избранное.
- Импорт проверяемого JSON-набора этажей в приложении, локальное хранение, поиск помещений и внутренние маршруты по графу. Архивные планы 3–5 этажей корпуса 6: 47 кабинетов, 44 подключены к графу. Общий выбор корпуса или кабинета в начале и конце маршрута. Уличный обход ориентировочный; входы и дорожки требуют уточнения.
- Мероприятия с источниками, избранным, проверкой пересечений с парами и переходом на карту.
- Импорт мероприятий из JSON и открытие формы события в системном календаре.

## Установка APK

Загрузите `uust-campus-0.2.2.apk` из раздела **Releases** репозитория, перенесите на телефон и откройте файл. Android может запросить разрешение на установку из используемого браузера или файлового менеджера.

Сборка подписана локальным ключом для тестирования. Ключ хранится только у разработчика: `tools/signing/campus-demo.jks`. Для обновления установленного приложения последующие APK необходимо подписывать тем же ключом.

## Разработка

Интерфейс написан на JavaScript, HTML и CSS без внешних библиотек времени исполнения. Android-оболочка на Java загружает встроенные ресурсы в WebView и получает JSON через HTTPS. Основные экраны работают самостоятельно. Для необязательных аккаунтов и общей афиши есть сервер Python: [инструкция запуска](docs/SERVER.md).

Быстрый предпросмотр на компьютере — Python 3.10+:

```powershell
python tools/preview.py
```

Откройте `http://127.0.0.1:4173`. Локальный сервер проксирует только предусмотренные запросы расписания. Для обновления нужен интернет; встроенные данные открываются без него.

## Сборка Android

Нужны Windows, PowerShell, Python, JDK 17 или 21, Android SDK Platform 35 и Build Tools 35.0.0. Android Studio и Gradle для текущего сборщика не обязательны.

```powershell
$env:JAVA_HOME = 'C:\path\to\jdk-21'
$env:ANDROID_HOME = 'C:\path\to\android-sdk'
.\tools\build.ps1
```

Или передайте пути явно:

```powershell
.\tools\build.ps1 -Sdk 'C:\path\to\android-sdk' -Jdk 'C:\path\to\jdk-21'
```

Результат: `artifacts/uust-campus-0.2.2.apk`. Сборщик использует временный каталог с ASCII-путём и нормализует имена ZIP-записей: это решает обнаруженные проблемы Windows-инструментов Android с кириллицей и вложенными ресурсами.

При отсутствии переменных скрипты содержат резервные пути окружения первоначальной разработки. На другом компьютере задайте свои `JAVA_HOME` и `ANDROID_HOME`.

## Проверки и текущий статус

```powershell
npm test
node tools/validate-maps.mjs
```

До первой передачи APK прошли 12 проверок логики: календарь, часовой пояс, поиск, соответствие корпусов, пересечения событий, импорт и обработка неверного ответа источника. В браузере проверены реальное обновление расписания и основные экраны. APK собирается, подписывается, устанавливается на Android 15; первый экран проверен на эмуляторе после исправления упаковки ресурсов.

**Полная проверка приложения на телефоне ещё не завершена.** По просьбе команды дальнейшие тесты остановлены для быстрой передачи APK. Подготовленный сценарий Android instrumentation ещё не запускался; его наличие не означает успешного прохождения:

```powershell
.\tools\test-android.ps1 -Serial emulator-5554
```

Запускайте его только на отдельном тестовом эмуляторе: он очищает локальный профиль этого приложения и временно отключает сеть эмулятора. Онлайн-обновление именно внутри Android APK и системные диалоги календаря/импорта требуют завершения проверки.

| --- | --- |
| `app/` | Интерфейс, предметная логика и репозиторий данных |
