# Кампус 0.3.2

## Единая карта

Территория и этажи теперь находятся на одном полотне. При приближении корпуса появляются его помещения, при отдалении снова видны номера корпусов. Чтобы посмотреть соседний корпус, достаточно перетащить карту. Кнопка возврата с этажа на территорию больше не нужна.

- Нажатие на корпус приближает его план; остальные корпуса остаются на карте.
- Поиск кабинета приближает нужное место и выбирает соответствующий этаж.
- Этаж выбирается вручную в полосе сверху. Для каждого корпуса сохраняется свой выбор в текущем сеансе карты.
- При перемещении карты переключатель относится к корпусу в центре видимой области. Корпуса без готовых планов остаются на общей схеме.
- Маршрут сохраняется при масштабировании и перемещении. Кнопки участков маршрута приближают соответствующую часть общей карты.
- Масштаб значков и подписей учитывает вложенные планы; мелкие номера появляются, когда для них достаточно места.
- Кнопка с рамкой показывает весь кампус. Карточку этажа можно закрыть, сохранив план на карте.

## Ограничения

Совмещение схематичное: планы сохраняют пропорции и размещаются в габаритах корпуса на исходной схеме. Фотографии не имеют измеренной привязки к территории. Это размещение используется только для отображения, не для расчёта длины пути, GPS или определения точного входа. Условное совмещение отмечено на карте; неизвестные связи входов не дорисовываются.

Состав этажей и граф маршрутов не изменены. Покрытие: основные этажи 1–5 корпуса 6, отдельное крыло «4,5», этажи 1–4 корпуса 7. Всего 121 помещение, 111 с узлом маршрута. Крыло «4,5» по-прежнему не связано с остальными этажами. Доступность проходов нужно сверить на месте.

## Передача команде

Тесты и браузерная проверка не запускались по просьбе владельца. Проверку поведения на телефонах выполняет команда. Обычный APK обновляет нашу установленную сборку; параллельный ставится рядом со сборкой сокомандника и обновляет прежний параллельный APK.
