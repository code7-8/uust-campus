# Границы проекта

- Репозиторий этого проекта: `code7-8/uust-campus` на GitHub. Он должен оставаться приватным, пока пользователь явно не попросит изменить видимость.
- Пользователь запретил использовать `moevm`: это организация/репозиторий его прошлого вуза. Не читать, не копировать материалы оттуда и не изменять её репозитории или настройки в рамках этого проекта.
- Не добавлять в Git токены, файлы `.env`, ключи подписи Android и локальные учётные данные. Готовые APK размещать в Releases.
